## 第4章 系统设计完成情况

### 4.1 系统总体设计

**完成状态：已完成基础设计。**

当前项目已采用前后端分离架构，并在仓库根目录完成基础工程划分：

| 层次 | 已完成内容 |
| --- | --- |
| 前端表现层 | `frontend/`，基于 Vue 3 + TypeScript + Vite |
| 后端服务层 | `backend/`，基于 Spring Boot + Maven |
| 接口层 | REST API，统一以 `/api` 开头 |
| 数据设计层 | `backend/src/main/resources/db/init.sql` |
| 部署层 | `deploy/`，包含 Docker Compose、Nginx、环境变量示例 |
| 文档层 | `docs/`，包含 API、数据库、启动和进度说明 |

当前已完成的系统功能结构包括：

1. 登录注册与 Token 认证。
2. 用户管理。
3. 赛事管理。
4. 赛题管理与认领。
5. WriteUp 知识库。
6. 训练任务与提交评分。
7. 通知公告。
8. 数据看板。

### 4.3 数据库设计

**完成状态：已完成初版表结构设计。**

当前已提供 `init.sql`，主要包含以下数据表：

| 表名 | 说明 |
| --- | --- |
| `sys_user` | 用户基础信息 |
| `sys_user_role` | 用户角色关系 |
| `competition` | 比赛信息 |
| `competition_problem` | 比赛赛题信息 |
| `cooperation_log` | 协同记录预留表 |
| `writeup_category` | WriteUp 分类 |
| `writeup` | WriteUp 内容 |
| `writeup_tag` | WriteUp 标签 |
| `training_task` | 训练任务 |
| `training_submission` | 训练提交与评分 |
| `notification` | 通知公告 |
| `notification_read` | 通知已读状态 |
| `operation_log` | 操作日志 |

**当前限制：** 后端目前仍使用 `InMemoryDataService` 作为内存数据服务，数据库脚本已准备好，但还没有真正接入 MySQL 持久化。

### 4.4 本章小结

第4章相关的系统设计已经具备基础材料：架构、功能模块、接口结构和数据库表设计均已形成。后续主要需要补充更正式的架构图、功能结构图、ER 图以及数据库字段说明。

### 5.3 当前实现不足

目前系统仍是 MVP 原型，主要不足如下：

1. 后端数据暂存在内存中，重启后会丢失。
2. 数据库脚本已写好，但还没有用 JPA/MyBatis 接入 MySQL。
3. 前端多数页面是基础展示，新增、编辑、删除等完整交互还需要加强。
4. 角色权限只有基础模型，接口级 RBAC 权限拦截还不完整。
5. WebSocket 实时协同、Redis 缓存、WriteUp 搜索暂未完成。
6. 测试用例和测试报告还没有系统化整理。

### 5.4 本章小结

第5章“系统实现”是目前完成最多的部分。项目已经具备前后端 MVP、主要业务接口、基础页面、部署配置和开发文档，可以作为后续联调、持久化和完善功能的基础。
